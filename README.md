# playwright-e2e-ecommerce-framework
Scalable Playwright E2E automation framework focused on quality engineering and real-world e-commerce flows.

This project demonstrates an enterprise-style approach to end-to-end test automation, using Page Object Model, business flow abstraction, headless execution and CI-ready practices to validate critical user journeys in an e-commerce application.

 🎯 Purpose
- This project was created to demonstrate a real-world approach to E2E test automation,
- focusing on maintainability, business flow abstraction and CI-ready execution,
-rather than isolated UI testing examples.

  🏗️ Architecture Overview
- Page Object Model for UI interactions
- Business flows to represent real user journeys
- Clear separation between test logic and business validation
- Headless execution by default, suitable for CI/CD pipelines

  ✅ Covered Scenarios
- User authentication
- Product selection and cart management
- Checkout and purchase completion
- Negative authentication scenarios

  ▶️ How to run
- npm install
- npx playwright test
